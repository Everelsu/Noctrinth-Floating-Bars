# Floating Bars — Noctrinth Theme

A pure CSS theme for **Noctrinth Launcher** that detaches the title bar, navigation rail, main viewport, and right sidebar into rounded floating islands.

## Features
- Pure CSS (no JavaScript worker required)
- Live toggle (`Floating layout`) via `data-plugin-*` attributes
- Customizable corner radius (`10px`, `16px`, `22px`) via CSS variables
- Customizable border accent tint with built-in color picker

## Install
Install directly from **Settings → Plugins → Catalog** in Noctrinth Launcher, or via deep-link:

```
noctrinth://plugin/install/floating-bars
```
